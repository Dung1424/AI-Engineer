# Chặng 3 Machine Learning

Tuần 11–16. Đầu vào là kiến thức Python, dữ liệu và toán nền tảng của hai chặng trước.

Học quy trình chia dữ liệu, baseline, model tuyến tính/cây quyết định, đánh giá và phân tích lỗi. Sản phẩm cuối có tập test riêng, pipeline đã lưu và báo cáo kết quả.

Thư mục này mới là khung để định vị chặng. Bài chi tiết sẽ được bổ sung khi tới đây.
