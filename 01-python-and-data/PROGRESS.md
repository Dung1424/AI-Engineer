# Tiến độ chặng 1

Chỉ đánh dấu sau khi tự làm, chạy kiểm tra và giải thích được kết quả. Bạn có thể sửa file này hoặc gửi bài cho mình review.

- [ ] 00 Tạo môi trường và tự chạy file Python.
- [ ] 01 Làm ba hàm về giá, phân loại điểm và đếm người đạt.
- [ ] 02 Tách dữ liệu đúng/sai bằng hàm và xử lý lỗi.
- [ ] 03 Đọc CSV, tính báo cáo và ghi JSON.
- [ ] 04 Tính theo cột, chuẩn hóa và kiểm tra shape bằng NumPy.
- [ ] 05 Làm sạch và nhóm dữ liệu bằng pandas.
- [ ] 06 Hoàn thiện pipeline, thử dữ liệu lỗi và chạy lại ra cùng kết quả.
- [ ] 07 Chạy project CRUD, thao tác qua giao diện, đọc request API và giải thích trách nhiệm của từng lớp.

## Bài đang làm

Chưa bắt đầu. Điền tên bài và ngày học khi bạn thực sự bắt đầu.

## Điều đã hiểu bằng lời của mình

Viết ngắn một khái niệm và một ví dụ bạn tự nghĩ ra.

## Lỗi đã gặp và cách sửa

Ghi đầu vào gây lỗi, thông báo và thay đổi đã giúp giải quyết.

## Câu muốn hỏi

Ghi đoạn code hoặc khái niệm cần giải thích tiếp.
